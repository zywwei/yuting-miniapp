## 二、设计方向：「成长手账」

温暖的纸质手账感——像翻开一本记录孩子成长的精装手账：奶油纸底色、圆角卡片、贴纸式标签、日期印章。与全局亲子粉统一，比绿色 Material 更柔软。

### 2.1 设计 Token（笔记模块专属，与全局 app.wxss 衔接）

```css
/* ===== 主色板 ===== */
--note-primary:    #FF8FA3;   /* 主粉：强调、主按钮 */
--note-primary-deep:#E8798F;  /* 按压/渐变末端 */
--note-cream:      #FFFBF5;   /* 手账纸底色（页面背景） */
--note-cream-dark: #F7F0E6;   /* 深色纸区（输入区、卡片底） */
--note-ink:        #4A3F35;   /* 主文字：暖棕黑（替代冷灰#333） */
--note-ink-light:  #A89B8C;   /* 次要文字 */
--note-gold:       #F0B429;   /* 印章/里程碑/置顶 */
--note-green:      #7FB069;   /* 成功/完成（原绿收敛为点缀色） */

/* ===== 卡片与层级 ===== */
--note-card-bg:    #FFFFFF;
--note-radius:     24rpx;
--note-shadow:     0 4rpx 20rpx rgba(74, 63, 53, 0.06);
--note-shadow-lift:0 8rpx 28rpx rgba(74, 63, 53, 0.10);

/* ===== 字号 ===== */
--note-fs-title:   36rpx;  /* 卡片标题 */
--note-fs-body:    28rpx;
--note-fs-aux:     22rpx;
```

类型徽章继续用 `note-types.js` 里已有的 13 组配色（浅底+深字），不改数据层。

## 三、界面美观方案

### 3.1 index 列表页 → 杂志化时间流

1. **头部**：绿色渐变 → 奶油底 + 大字标题"成长手账"（44rpx 暖棕黑）+ 副标题统计（"共 N 篇 · 连续记录 X 天"）。搜索按钮改为圆形白底立体小钮；主入口"+ 写笔记"改为右下角**悬浮圆形 FAB**（主粉、60rpx ➕、阴影悬浮），随时可记。
2. **按月分组**：列表按月份插入分组标题（如"2026 年 7 月 · 12 篇"），标题用印章式小标签。成长记录的核心爽点是"翻时间"。
3. **卡片升级**：
   - 有图笔记：缩略图从右侧 140rpx 小方图 → 顶部横图大卡（宽 100%、高 260rpx、圆角上沿），图文杂志感；多图角标保留。
   - 无图笔记：文字卡，标题左侧加 4rpx 类型色竖条。
   - 心情 icon 从头部挪到卡片右下角做"贴纸"（旋转 -8deg、半透明底托）；置顶笔记显示 📌 金签。
   - 卡片入场 stagger 动画（0.05s 间隔 fadeInUp，仅首屏前 10 张）。
4. **分类 Tab 收纳**（兼治 B1）：13 个平铺 → "全部 + 4 分组入口（日常/学习/生活/成长）"，点分组弹出半屏面板展示该组类型网格选择；已选类型在 Tab 栏回显。
5. **空状态**：emoji → 场景化插画组合（📖+✏️+🌱 三元素错落 + 一句温暖文案 + 主粉 CTA 按钮）；搜索无结果给"清空筛选"快捷钮。

### 3.2 detail 详情页 → 杂志排版

1. **Hero 区**：有首图时全宽大图（高 420rpx）+ 底部渐变遮罩，标题压图上；无图时类型色浅底 banner。
2. **作者行**：作者头像 + 角色名 + 发布日期 + visibility 图标，一行卡片化（现在只有一行小灰字）。
3. **正文**：rich-text 排版优化——字号 30rpx、行高 1.8、段间距 24rpx；标题 36rpx。
4. **心情与标签**：心情大 icon + 文字标签展示（"今天很兴奋 🤩"），标签改为贴纸样式。
5. **底部操作栏**：固定底栏——❤️ 点赞（接入 like-bar）、💬 评论数、✏️ 编辑、🗑 删除（仅 canEdit 显示后两者）；替换现在两个生硬的宽按钮。
6. **上下篇导航**（兼治 B7）：底栏加"上一篇 / 下一篇"箭头（按当前列表排序上下文）。
7. **评论区**：接入 `comment-section` 组件（见 C1）。

### 3.3 add 编辑页 → 沉浸写作台

1. **页面结构**：从"长表单"改为"写作优先"——标题/正文占首屏 70%，其余选项收进底部**可上拉抽屉**（类型、心情、标签、照片、可见范围，分 Tab 收纳）。
2. **格式工具栏**（兼治 B4）：正文 editor 上方加浮动工具条——**B 加粗 / I 斜体 / U 下划线 / 无序列表 / H2 小标题 / 清除格式**，调 editorContext.format API，纯前端能力。
3. **类型/心情选择**：折叠面板 → 底部抽屉内的网格选择器（类型 4 列网格、心情 5 列网格），选中项主粉描边 + 弹跳动效。
4. **可见范围**：三选项改为分段控件（segmented control），指定成员头像横排多选保持不变。
5. **字数提示**：标题 30 / 正文 500 的实时字数（"128/500"）放输入框右下角，超 80% 变橙提醒。

## 四、操作体验方案

| # | 优化 | 实现要点 |
|---|---|---|
| OP-1 | **草稿箱**（B3） | 编辑页输入防抖 1s 后自动存本地草稿 `note_draft_<id|new>`；异常退出后再次进入编辑页提示"检测到未完成的草稿，恢复？"；保存成功后清草稿。纯本地存储，不动云端 |
| OP-2 | **左滑跟手**（B2/D1） | touchmove 实时更新单卡 translateX（用 `wxs` 或只 setData 当前 index 项），删除按钮随动露出；松手超阈值吸附展开、否则回弹；不再全量刷新数组 |
| OP-3 | **照片排序**（B5） | 长按照片进入排序模式（震动反馈），拖动换位（ movable-view 或 touch 计算目标位）；上传 Loading 从全屏改为照片占位块局部 loading，不阻塞继续写作 |
| OP-4 | **标签推荐**（B6） | 输入标签时下方实时展示历史标签模糊匹配 chips（取 `_tagIndex` 已有数据），点选即填；标签按使用频次排序 |
| OP-5 | **搜索历史 + 高亮**（B8） | 最近 10 条搜索词存本地，聚焦搜索框时展示；结果列表标题/摘要中关键词包 `<text class="hl">` 主粉高亮 |
| OP-6 | **键盘适配** | editor `adjust-position` 已默认；工具条随键盘上浮（`keyboardheightchange` 监听），收起键盘自动隐藏 |
| OP-7 | **反馈统一** | 保存/删除/上传失败等 toast 文案与时长统一封装；删除成功改"撤销条"（5s 内可撤销，先本地删、撤销则回插，超时再发云端删除） |

## 五、功能增强方案

### F1. 接入点赞 / 评论（C1，高价值低成本）
- detail 页底栏接 `like-bar`，正文下接 `comment-section`（两组件与 `interaction` 云函数均已就绪）。
- 列表卡片显示 ❤️/💬 计数角标（数据走 `fetchNotes` 时聚合或详情页首次加载回填本地）。
- 前置检查：两组件年久未用，先核对其字段与 interaction 云函数当前接口是否匹配，不匹配则以云函数为准改组件。

### F2. 时间轴 / 日历视图（C2，核心场景）
- 列表页头部加视图切换：「列表 / 日历」。
- 日历视图：月历格子，有笔记的日期显示类型色小圆点（多类型多色），点日期下方纵向列出当日笔记卡。
- 纯前端实现：`_allNotes` 已有全量数据，按 createTime 建日期索引即可，不动云端。

### F3. 笔记置顶（C3）
- 数据：`note.pinned: true`（云端 notes 集合加字段，`record` 云函数 update 白名单确认放行）。
- 交互：列表卡片长按菜单"置顶/取消置顶"；排序规则 pinned 优先、组内仍按时间。

### F4. 语音笔记（C4）
- 编辑页加"按住说话"（`RecorderManager`，≤60s），保存为 voice 字段上传云存储（`notes/` 目录，删除清理逻辑已兼容）。
- 详情/列表播放：圆形播放钮 + 音波动效（`InnerAudioContext`）。
- 工作量中等，建议排在 F1-F3 之后。

### F5. 分享卡片（C5）
- detail 页加"生成分享图"：canvas 绘制 3:4 卡片（手账纸底 + 标题 + 首图 + 日期印章 + 小程序码），保存相册。
- 纯前端 canvas，无云端改动。

### F6. 心情与记录统计（C6/C7）
- 列表头部统计条："本月 N 篇 · 连续 X 天 · 最多心情 😊"。
- 按月心情分布小条形图（纯 view 宽度百分比，不引图表库）。

## 七、约束与风险

1. **不回退安全修复**：本计划所有改动避开 07-08 Review 已修的权限过滤、云文件清理、字段校验逻辑；列表 `loadNotes` 的 visibility 过滤兜底必须保留。
2. **数据兼容**：新增 `pinned`/`voice` 字段对旧数据无侵入（缺省即 false/空）；草稿箱仅本地 key，不污染云端。
3. **性能**：按月分组/日历索引基于 `_allNotes` 前端计算，千级数据量下无压力；stagger 动画限首屏前 10 张卡片。
4. **组件风险**：comment-section/like-bar 是死代码，接入前必须先与 interaction 云函数联调核对（字段、分页、familyId 过滤）。
5. **editor 工具栏**：`editorContext.format` 依赖微信基础库 2.7.0+，项目满足；iOS 上 format 后光标位置需实测。
