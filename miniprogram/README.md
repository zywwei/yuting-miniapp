# 🌱 钰婷成长小助手 - 儿童成长陪伴小程序

一款专为朱钰婷（2022年3月23日出生）设计的儿童成长陪伴微信小程序，涵盖习惯养成、学习乐园、创意天地、成长笔记等模块，陪伴孩子健康成长。

## ✨ 功能特色

### 🎯 习惯养成
- 刷牙打卡（保留原有功能）
- 作息打卡（早起/早睡）
- 运动打卡（跳绳、跑步等）
- 阅读打卡
- 自定义习惯（家长可添加）
- 习惯统计和连续打卡天数

### 📚 学习乐园
- 识字卡片（120个常用汉字，配拼音和释义，按类别分组）
- 古诗背诵（25首经典古诗，含唐诗宋词）
- 数字启蒙（1-100数字学习，含中文对照和测验模式）
- 英语单词（100个基础英语单词，配音标和释义）
- 学习进度追踪
- 家长可自定义添加学习内容

### 🎨 创意天地（保留原有功能）
- 自由画画
- 涂色模板
- 亲子画画
- 我的画廊

### 📝 成长笔记
- 成长日记记录
- 心情选择（开心/兴奋/平静/累了）
- 标签分类
- 笔记列表和详情查看

### 🏠 首页
- 今日待办习惯展示
- 快捷入口导航
- 今日推荐内容
- 成就墙展示

## 🚀 使用方法

1. 下载并打开**微信开发者工具**
2. 导入项目，目录选择 `miniprogram`
3. 在开发者工具中开通**云开发**（免费额度足够）
4. 点击编译即可预览

## ☁️ 云开发配置步骤

### 第一步：开通云开发
1. 打开微信开发者工具
2. 点击左上角「云开发」按钮
3. 点击「开通」，选择免费基础版
4. 记录分配的环境ID

### 第二步：创建数据库集合
在云开发控制台 → 数据库，创建以下集合：
- `drawings`（画作记录）
- `brushingRecords`（刷牙打卡记录）

### 第三步：设置权限
两个集合的权限都设置为「所有用户可读，仅创建者可读写」
