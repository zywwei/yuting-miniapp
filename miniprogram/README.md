# 🎨 钰婷的小画板 - 亲子涂鸦互动小程序

一款专为朱钰婷（4岁）设计的亲子涂鸦画画微信小程序。

## ✨ 功能特色

### 🖌️ 自由画画
- 16种画笔颜色可选
- 5种画笔粗细调节
- 橡皮擦功能
- 多步撤销操作
- 一键清空画布

### ⭐ 贴纸/印章
- 32种可爱贴纸可选（爱心、星星、动物、水果等）
- 触摸画布即可放置贴纸
- 贴纸大小可随画笔粗细调节
- 支持拖拽移动、双指缩放/旋转

### 🖼️ 涂色模板
- 11种 Canvas 线稿模板
- 6大分类（动物、植物、交通工具、食物、卡通）
- 在真实线稿上进行涂色创作

### 📷 照片背景
- 从相册选照片或拍照作为画画背景

### 🏠 成长画廊
- 按时间线展示画作（今天、昨天、本周、本月、更早）
- 统计总画作数、连续创作天数、本月创作数

### 🦷 刷牙打卡
- 早晚两次打卡
- 拍照记录 + 家长评分
- 2分钟刷牙计时器
- 6区域自动切换
- 可爱牙齿角色动画
- 连续打卡天数统计

### ☁️ 云端同步（云开发）
- 画作和打卡记录自动上传云端
- 本地缓存 + 云端同步（离线也能用）
- 多设备查看（爸爸和妈妈都能看到）

## 🚀 使用方法

1. 下载并打开**微信开发者工具**
2. 导入项目，目录选择 `miniprogram`
3. 在开发者工具中开通**云开发**（免费额度足够）
4. 点击编译即可预览

## ☁️ 云开发配置步骤

### 第一步：开通云开发
1. 打开微信开发者工具
2. 点击左上角「云开发」按钮
3. 点击「开通」，选择免费基础版
4. 记录分配的环境ID

### 第二步：创建数据库集合
在云开发控制台 → 数据库，创建以下集合：
- `drawings`（画作记录）
- `brushingRecords`（刷牙打卡记录）

### 第三步：设置权限
两个集合的权限都设置为「所有用户可读，仅创建者可读写」
