# 🌱 钰婷成长小助手 - 儿童成长陪伴小程序

一款专为儿童设计的成长陪伴微信小程序，涵盖习惯养成、学习乐园、奇趣屋（画画+摆摊）、成长笔记、家庭管理等模块，陪伴孩子健康成长。

## ✨ 功能特色

### 🏠 首页
- 今日待办习惯展示
- 快捷入口导航
- 今日推荐内容
- 成就墙展示
- 家庭切换（支持多家庭）

### 🎯 习惯养成
- 刷牙打卡（计时器+战斗系统+故事剧情）
- 作息打卡（早起/早睡）
- 运动打卡（跳绳、跑步等）
- 阅读打卡
- 自定义习惯（家长可添加）
- 习惯统计和连续打卡天数
- 特色打卡表单（每种习惯有不同的表单字段）

### 📚 学习乐园
- 识字卡片（120个常用汉字，配拼音和释义）
- 古诗背诵（25首经典古诗）
- 数字启蒙（1-100数字学习）
- 英语单词（100个基础英语单词）
- 学习进度追踪

### 🎪 奇趣屋
#### 🎨 画画
- 自由画画（16色画笔、5种粗细、橡皮擦、撤销、贴纸）
- 涂色模板（11种线稿模板，6大分类）
- 一起画画（多人协作）
- 我的画廊（时间线展示、统计）

#### 🏪 摆摊（进销存系统）
- **商品管理**：添加/编辑/删除商品，支持照片、分类、进货价/售价
- **快速开单**：选择商品、数量调节、找零计算器、一键收款
- **销售历史**：按日期分组、筛选、删除（自动回滚库存）
- **统计报表**：销售额/利润/热销商品排行、趋势图
- **价目表**：全屏展示给顾客看，支持横屏
- **找零计算器**：大数字显示，常见面额快捷按钮
- **摊位等级**：路边摊→小地摊→小店铺→大商铺→连锁店（5级）
- **每日目标**：设定销售目标，进度条实时显示
- **连续营业打卡**：记录连续营业天数

### 📝 成长笔记
- 成长日记记录
- 心情选择（开心/兴奋/平静/累了）
- 标签分类
- 照片附件（支持云存储）

### 👨‍👩‍👧 家庭系统
- 多成员支持（爸爸、妈妈、爷爷、奶奶等）
- 多孩子支持（每个孩子独立数据）
- 角色权限管理（管理员/成员）
- 邀请码加入家庭
- 成员禁用/启用
- 家庭切换（支持加入多个家庭）

### 🏆 成就系统
- 刷牙成就（连续3/7/30天）
- 习惯成就（连续打卡、全勤）
- 学习成就（识字、古诗、数字、英语）
- 画画成就（创作数量、连续创作）
- 摆摊成就（销售笔数、销售额、利润、商品种类）
- 特殊成就（早起、晚睡、周末战士等）

### ☁️ 云端同步
- 画作、打卡记录、笔记自动上传云端
- 摆摊商品/销售记录云同步
- 本地缓存 + 云端同步（离线也能用）
- 多设备数据同步

### 📤 数据备份
- 导出所有数据为 JSON 文件（含图片 base64）
- 从备份文件恢复数据
- 支持分享备份文件到微信

## 🚀 使用方法

1. 下载并打开**微信开发者工具**
2. 导入项目，目录选择 `miniprogram`
3. 在开发者工具中开通**云开发**（免费额度足够）
4. 点击编译即可预览

## ☁️ 云开发配置步骤

### 第一步：开通云开发
1. 打开微信开发者工具
2. 点击左上角「云开发」按钮
3. 点击「开通」，选择免费基础版
4. 记录分配的环境ID

### 第二步：创建数据库集合
在云开发控制台 → 数据库，创建以下集合：
- `drawings`（画作记录）
- `brushingRecords`（刷牙打卡记录）
- `families`（家庭信息）
- `familyMembers`（家庭成员）

### 第三步：设置权限
集合权限设置为「所有用户可读，仅创建者可读写」

### 第四步：部署云函数
右键点击 `cloudfunctions` 目录下的云函数，选择「上传并部署」
